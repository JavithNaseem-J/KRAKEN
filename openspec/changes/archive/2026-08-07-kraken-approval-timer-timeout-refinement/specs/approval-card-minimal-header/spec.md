# approval-card-minimal-header Specification

## ADDED Requirements

### Requirement: Minimal Approval Header
The system MUST render a minimal header bar (`Action Approval Gate`) omitting shield icons, verbose authorization texts, action badges, and risk level tags.

#### Scenario: Approval Card Header
- **WHEN** an approval card renders
- **THEN** the header displays `Action Approval Gate` and subtitle `Security clearance required before proceeding`.
