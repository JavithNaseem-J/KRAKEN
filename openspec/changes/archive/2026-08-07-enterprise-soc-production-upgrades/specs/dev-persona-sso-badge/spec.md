# dev-persona-sso-badge Specification

## ADDED Requirements

### Requirement: Developer Testing Persona Badge
The system MUST display a `Developer Testing Persona` badge in the sidebar role switcher area.

#### Scenario: Displaying persona switcher label
- **WHEN** the sidebar persona switcher renders
- **THEN** a `Developer Testing Persona` badge is displayed to distinguish local role testing from enterprise SSO auth.
