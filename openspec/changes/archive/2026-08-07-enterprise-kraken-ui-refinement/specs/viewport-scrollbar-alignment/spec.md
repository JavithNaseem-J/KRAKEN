# viewport-scrollbar-alignment Specification

## ADDED Requirements

### Requirement: Far Right Viewport Scrollbar
The system MUST position the chat message stream vertical scrollbar track at the far right edge of the main window.

#### Scenario: Scrolling chat message history
- **WHEN** chat messages overflow the viewport height
- **THEN** the vertical scrollbar track renders on the far right edge of the screen rather than floating next to the message column.
